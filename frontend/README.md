# Frontend - Nissan Universidad

Cliente SPA en React + Vite para el ERP de Nissan Universidad.

## Comandos

- `npm run dev`: Inicia el servidor de desarrollo en `http://localhost:5173`.
- `npm run build`: Empaqueta para producción.

Para iniciar todo el sistema con el backend, usa el script `../iniciar_sistema.sh` desde la raíz.
